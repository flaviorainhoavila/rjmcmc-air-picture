# rjmcmc-air-picture

**Tracking an unknown number of aircraft with a miscalibrated radar, using sequential reversible-jump MCMC.**

> Status: in progress. Results below are generated by the benchmark script and are filled in only from actual runs.

## The problem

Two radars watch the same airspace. Radar A is calibrated. Radar B has a **range offset and an azimuth alignment error that nobody has measured**. Aircraft enter and leave the scene, detections are missed, and clutter produces false alarms.

A standard tracker that ignores Radar B's bias sees the same aircraft in two slightly different places and builds **duplicate tracks**. Its uncertainty estimates are also overconfident, because the bias is not in its error model.

This project estimates, jointly and sequentially:

- **how many aircraft exist** (the number changes over time),
- **where each one is and how it is moving**,
- **Radar B's bias** (range offset and azimuth error),

and projects each track forward with its uncertainty.

## Approach

- **Sequential MCMC with reversible-jump moves.** At each scan, a Markov chain explores the joint posterior of the number of targets, their states and the sensor bias. Moves:
  - **birth and death:** dimension-changing moves for a new or vanished aircraft;
  - **target update:** refresh the state of an existing target;
  - **bias update:** refresh Radar B's range and azimuth bias.
- **Models:** a nearly-constant-velocity motion model and a polar (range and bearing) measurement model, with probability of detection below one and Poisson clutter.
- **Baseline:** global-nearest-neighbour association with an extended Kalman filter (GNN-EKF) and M-of-N track management, ignoring the bias. An oracle variant with the true bias known is included for reference.
- **Origin:** this adapts the RJ-MCMC and blind distortion-identification ideas from my audio-restoration research (Bayesian restoration of audio degraded by impulsive noise, IEEE TASLP 2012) to multi-target tracking: there, an unknown number of impulses at unknown positions; here, an unknown number of aircraft and an unknown sensor distortion.

## Metrics

- **OSPA** (cut-off *c* and order *p* stated in the config): overall multi-target error, covering both position and cardinality.
- **Cardinality error and duplicate-track count:** whether the tracker sees the right number of aircraft.
- **Position NEES:** whether the reported uncertainty matches the actual error. For 2-D position the ideal mean is 2.
- **Bias estimation error:** range offset (m) and azimuth error (mrad) against the truth.
- **Forecast coverage:** fraction of future true positions inside the predicted 95% regions.
- **Runtime per scan.**

## Running it

```bash
uv sync
uv run pytest
uv run python -m airpicture.experiments.run_benchmark --config configs/benchmark.yaml
uv run python -m airpicture.experiments.report
```

Every scenario is generated from a fixed seed, so results are reproducible.

## Repository layout

```
src/airpicture/
  models.py        motion and measurement models
  sim.py           scenario generator: births, deaths, misses, clutter, sensor bias
  gnn_ekf.py       baseline tracker
  rjmcmc.py        sequential RJ-MCMC tracker with joint bias estimation
  metrics.py       OSPA, NEES, cardinality, duplicates, coverage
  experiments/     benchmark runner and report generator
configs/           scenario and tracker settings
tests/             unit and statistical tests
results/           generated outputs (JSON and figures)
docs/writeup.md    method and results write-up
```
